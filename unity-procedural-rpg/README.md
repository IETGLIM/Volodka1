# ProceduralRPG - Unity URP 2022.3 LTS

This folder is a self-contained, code-only rendering foundation for a
procedural RPG. It uses no imported FBX, PNG, AudioClip, or texture asset.
Meshes, characters, materials, ambient sound, SDF forms, and generated maps
are made at runtime.

## Target

- Unity 2022.3 LTS
- URP 14
- Packages: Burst, Mathematics, Collections, Jobs (installed by default in a
  new URP project; enable Burst in `Jobs > Burst > Enable Compilation`).
- Compute shaders require DX11/12, Vulkan, Metal, or a similar compute-capable
  graphics backend.

## Install

1. Create a fresh **3D URP** project in Unity 2022.3 LTS.
2. Copy the `Assets/ProceduralRPG` directory from this folder into your Unity
   project `Assets/` directory.
3. Create an empty GameObject named `Procedural RPG`.
4. Add `ProceduralSceneManager` and assign the three shader assets and the
   compute shader in its inspector.
5. Open your URP Renderer Data asset and add these Renderer Features:
   `VolumetricFogFeature`, then `AutoColorGradeFeature`. Assign their shaders.
6. Press the component context-menu item **Generate Entire Scene** or hook the
   public `GenerateEntireScene` method to a UI Button.

## Intentional quality constraints

The default texture resolution is 1024. A full set of four 2048 maps is
approximately 256 MB per material in uncompressed RGBA format, so use 2048
only for hero objects via the inspector. Every material remains generated by
compute shader and cached as RenderTextures for the current session.

## Files

- `Scripts/World/SdfWorldGenerator.cs`: Burst field evaluation + marching
  tetrahedra world meshes; smooth SDF unions of spheres, boxes, cylinders.
- `Scripts/Characters/ProceduralCharacter.cs`: generated body, harmonic face,
  generic limb rig.
- `Scripts/Characters/FabrikFootIK.cs`: procedural FABRIK legs and arms.
- `Scripts/Materials/ProceduralMaterialBaker.cs`: Compute Shader map baker.
- `Scripts/Materials/SurfaceDirtController.cs`: rain and dirt accumulation.
- `Scripts/Audio/ProceduralSoundscape.cs`: generated PCM ambience and audio
  driven shader pulse.
- `Scripts/Core/ProceduralSceneManager.cs`: one-button scene generator.

The module targets URP. SDF, mesh, character, IK, compute texture, audio, and
surface data code is pipeline agnostic. HDRP needs HDRP Custom Pass equivalents
for the two renderer features and a ShaderGraph/HDRP version of the URP surface
shader; do not attempt to drop URP shader passes into HDRP unchanged.
