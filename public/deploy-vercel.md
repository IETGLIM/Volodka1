# Как задеплоить «Володьку» на Vercel

Брат, ты просил архив, но в этой среде (Web-IDE) нельзя просто скачать `.zip` файл на твой компьютер. Зато ты можешь задеплоить игру прямо из этого проекта, скопировав нужные папки к себе в репозиторий.

Весь код, который я написал, собирается в **один HTML-файл** со всеми встроенными скриптами и стилями (спасибо плагину `vite-plugin-singlefile`), плюс папка `public` с картинками.

## Вариант 1: Самый быстрый деплой (только готовый билд)

Если ты хочешь просто посмотреть результат на Vercel прямо сейчас, без возни с исходниками:

1. Открой папку `dist` в этом редакторе.
2. Там лежат файлы готовой игры (например, `index.html` и папка `art/`).
3. Скачай/скопируй их к себе на компьютер в отдельную пустую папку (назови её, например, `volodka-build`).
4. Установи Vercel CLI (если нет): `npm i -g vercel`.
5. Открой терминал в папке `volodka-build` и введи:
   ```bash
   vercel --prod
   ```
   Всё! Игра будет в сети.

## Вариант 2: Загрузить исходники в твой GitHub

Если хочешь перенести весь мой код в твой репозиторий `IETGLIM/Volodka`:

1. Скопируй из этой среды следующие папки и файлы:
   - `src/` (весь исходный код)
   - `public/` (картинки, фоны, этот мануал)
   - `index.html`
   - `package.json`
   - `vite.config.ts`
   - `tsconfig.json`
   - `vercel.json` (настройки роутинга для Vercel)
2. Замени ими аналогичные файлы в твоём репозитории.
3. Запушь в `main`.
4. Vercel автоматически подхватит изменения, запустит `npm run build` и обновит твой сайт `volodka.vercel.app`.

**Что было сделано для AAA-ощущений в этой версии (без внешних моделей):**
- **Полноценные люди вместо кубоидов:** у Володьки и NPC есть лица, одежда, волосы, пальцы, плащи.
- **Сгибание коленей и локтей:** добавлена кинематика при ходьбе (руки и ноги теперь сгибаются в суставах).
- **Плавность:** все модели генерируются из 32-сегментных сфер и капсюлей (никаких острых углов).
- **SSAO (Ambient Occlusion):** добавлены объёмные тени во все складки и углы (включается на качестве "Высокое ✦").
- **Живая камера и физика:** камера покачивается при ходьбе, ноги адаптируются к рельефу (IK), пыль из-под сапог.
- **Боёвка и лут:** 3 комбо-удара, хитстоп, мобы, физический лут (эхо строки, рябина), инвентарь и лечение.
